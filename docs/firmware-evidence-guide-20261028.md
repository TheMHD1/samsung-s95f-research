## Filesystem and source results

The two actual GPT/VDFS2007 partitions were read inside a private unprivileged namespace without mounting an image, loading a filesystem driver or executing OEM programs. Both extraction runs reported zero file failures; an independent no-follow tree walk corroborated regular byte totals. Main catalog file-record count is58,457 and product count1,122. Host extraction yielded57,038/912 regular files and3,369/210 symlinks, with2,435,829,478 regular bytes total. Catalog records, hard-link materialization and unique host files are different counts; this is not a metadata-faithful filesystem backup or rebuild result. Compressed metadata CRC and exact output lengths were checked; file RSA/per-chunk authentication and complete filesystem semantics remain unproved.

The included original Rust reader patch adds source-backed compressed-extent handling, checked sizes/CRC/path components and zero-error extraction receipts. Reproduce it from the pinned linked upstream commit under its MIT license; the upstream checkout and OEM extracted tree are not vendored. The GPL format-driver reference remains separately attributed and was never loaded.
