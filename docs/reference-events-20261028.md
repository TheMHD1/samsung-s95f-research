# Reference events, quiescent intervals and bounded diagnostics

This additive checkpoint develops the reference-refresh work into a reusable observation method. It preserves the original rejected dense collector, separately classifies a later fault and recovery, and adds a reader that distinguishes ordinary-gate-off intervals from clean and faulted states. The purpose is to locate actual state transitions and improve logging placement. No prevention fix, installed controller hook, lane-table modification or physical-output measurement is established.

The earlier [reference-refresh guide](reference-refresh-20261028.md) remains the source map for selector copies, separate mirrors and the two-boundary-event counter. Its observations and the four published scientific fixtures retain their original scope and bytes. New source and actual observations below do not rewrite those historical outcomes.

## A runtime diagnostic is not a blanket bypass

[EK's design and independent review](../research/panel-idle-20261026/overnight/single-lane-diagnostic-design-20261028ek/reviews/README.md) examine a possible single-lane primary-word change at lane570. The design has no deployed data-write helper. The primary word owns all16 bits; the bit0 skip condition is local permission only if execution reaches that lane. Guarded snapshots and full-table comparison reduce interference but cannot prove continuous writer inactivity or distinguish an intervening stock ABA sequence.

The protocol's most important boundary is global: after an ambiguous OUT, **issue no further OUT of any kind**. A later read header, restore header, another tool or mode command could be consumed as the outstanding write payload. Immediate restore is therefore not guaranteed. With an exact fixed accepted header, a sole bounded2-byte payload and that no-extra-OUT invariant, the intended unresolved effect is one runtime data word; this is distinct from an established code, boot, flash or network-configuration write. It is not an unconditional safety proof or an approved ambiguous-phase recovery route. MODE2 is not proved to restore the lane mask.

Pure host models exercise integer widths, table-bit preservation, sampled ownership and fail-closed phase handling without a target binding. They provide actionable design constraints rather than an impossible claim to prove every writer absent. A future experiment still needs its separately reviewed fixed implementation, current source/context binding, an explicit ownership/restore ledger and a stopping plan that preserves unknown phase.
