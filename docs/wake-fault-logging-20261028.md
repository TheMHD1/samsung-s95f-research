The GF candidate is1,196bytes with NORMAL invocation-counter56,21formatted details and two12-byte event736 lines. Baseline has no exact736line; post has two. The candidate contains all changed backing data, but endpoint cursor arithmetic does not prove no laps, consumer ownership, chronology or a shared dispatch epoch. [FR's source audit](../research/panel-idle-20261026/overnight/rtp-normal-header-trace-20261028fr/README.md) distinguishes the NORMAL invocation counter, publication ordinal, current dispatch count, delayed history and aggregate H. The omitted callbacks include data aggregation, hardware action and formatter side effects; this is not a full controller or panel simulation. Its alternate-selector40/200 results are conditional experiments, not recovered live FP or proof that a future200change is safe or sufficient. OEM instructions and third-party emulator distributions are not bundled here. Source-audit reproducers require the separate pinned inputs they declare.

```sh
python3 -B tools/verify_wake_onset.py --fixture fixtures/wake-gc.json
python3 -B tools/verify_wake_onset.py --fixture fixtures/wake-gf.json
python3 -B -m unittest discover -s tests -p 'test_wake_onset_fixture.py'
python3 -B -O -m unittest discover -s tests -p 'test_wake_onset_fixture.py'
```

These are the seventh/eighth fixtures. Each removes both dynamic pointer words from the58-byte native row, retaining50scientific bytes per sample and selected full R/M/C/N/H observations for independent raw/compact recomputation. Typed ring details and the paired event suffix replace full ring bodies. The standalone verifier checks row counts/states, sampled H, full retained bytes/times, key ordering, logger readback and bounded detail arithmetic; meaningful rehashed mutations must fail. It explicitly does **not** replay private authenticated transport provenance, OEM instructions, identities or raw ring history. The private builder is supplied for independently held inputs; the public clone requires neither those inputs nor a connected television.
