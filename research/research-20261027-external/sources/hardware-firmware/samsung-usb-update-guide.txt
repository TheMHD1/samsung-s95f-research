                       USB Update Guide

 Updating with a USB drive

1 Press the Home button on your TV remote,
  Then navigate to Setting > All setting > Support > About TV and check the
  Model Code and Software Version of your TV.




2 Go to Samsung.com > Support > Manual & Software, and search for your
  Samsung TV Model Code.
3     Download the update file for that model to PC.

      If the main version of the TV's software is lower than the target upgrade version,
      download the "Upgrade File (USB Type), Main" and unzip it.


※ Download software upgrade files




4 Connect a USB device to your PC, and save the unzipped files to the USB device.

     Save the update files in the top-level folder, which is the first folder that you see when
     you select the USB device.

     If you place them in subfolders, they will be not accessible by the TV.

                                                         ※ Top-level folder for software upgrade




※ When unzipping, Folders are not updated when they are created with the compressed file name.
    Unzip without creating a folder. Ex) "Unzip here“
※ The names of the file and folder may vary depending on the model.
※ Sometimes, it can include multiple folders at once.
    In this case, please unzip the multiple folders at once and save them to the USB device.
