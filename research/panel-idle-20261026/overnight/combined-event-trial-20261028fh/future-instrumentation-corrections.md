# Source-directed corrections for a future combined recorder

These are design requirements arising from the original refused FH trial and early FM review. They do not modify frozen FG or promote FH to acceptance. The separate fixed FM restore owner remains the immediate priority.

1. Separate initial profile from permissible runtime transition. FL proves C8zero is stock runtime reachable, independently of C7/root/logger. Initial arming can retain3; later observation/cleanup needs a source-qualified narrow transition policy. Recovered global values0..4 are positive witnesses, not a complete exhaustive invariant. No arbitrary context drift is admitted.
2. Distinguish semantic observation refusal from unknown transport/clock failure. A full-pair semantic exception currently sets o.Error and blocks all FG cleanup. Any successor may attempt its separately guarded fresh-context cleanup only at positively ReadyForHeader with sufficient budget and valid binding/context. A transport ambiguity, accepted header pending payload/IN, or clock loss must still prevent new headers. Do not globally ignore o.Error.
3. Commit an already-zero restoration outcome only after its final full readback verifies zero. Early FM inspection found a path assigning already-zero-no-write before that read; a later drift/short/clock error could leave loggerMayRemain=false without verified closure. Correct the state machine and exercise initialzero→finalone, upper-bit drift and transfer/clock failures. This is a reported candidate defect, not a claim that it occurred in FH (FH had gate1/no restore).
4. Preserve the primary native refusal explicitly before optional sidecar interpretation. FH native acceptedfalse/knownReady/closed is followed by empty post-ring; strict bind_rings then raises complete-ring, masking the immediate cause in the CLI exception and leaving generic wrapper inflight status. A successor should retain a typed refused outcome with separate known-phase/lifecycle facts, without accepting incomplete rings, inventing cleanup, or sending new controller requests. Exact owned-stage reconciliation remains separate.

Native timing/exposure qualification, fixed40, exact logger address/payload, matching-IN/payload obligations, ownedFD/binding, freshM/C/R, readback, per-call/root caps and honest physical/causal limits remain required. An instrumentation fix is not the requested panel-prevention fix. The raised-limit lead and decision-time operand blindspots remain separate investigation work.
