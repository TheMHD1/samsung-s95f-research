# Fixed zero-vendor claim diagnostic

This probe opens only USB bus7/device58/interface2 on the pinned current boot. It verifies root ARM32 ABI, full cached descriptors, sysfs configuration and FD character-device identity, then performs one interface claim and one release/close attempt. It has no USB bulk/control transfer implementation, vendor memory header, controller address/value, UI, reset, detach, retry, background process or arbitrary CLI input. GETDRIVER is the fixed cache-only kernel ioctl0x41045508 with260-byte interface2/name buffer; it is not a USB control request.

Pre/post claim observations retain each .NET LinkTarget, ResolveLinkTarget(true), Directory.Exists and File.Exists result or exception separately, plus native readlink, statx following/not following the driver link, kernel GETDRIVER and FD statx identity. Preclaim must be unbound. After successful claim there is deliberately no expected driver-path gate: recording the actual values is this probe's purpose. Accepted means completed diagnostic lifecycle with release/close; driverPolicyEstablished and physicalPictureObserved stay false. Unknown postclaim driver metadata is not turned into ownership or queue proof.

Structured selftest/native receipts are exclusive0600fixed-name files in a fresh0700 `/tmp/researcher-do-<32hex>` stage. Diagnostics remain separately bounded stdout. The wrapper inherits reviewed DN staging/auth/readiness/census and three-blob framing, saves receipts before strict parsing, validates zero vendor counts and fixed identity, and hashes the exact nine-file inventory before accepted-only cleanup. Failure/ambiguity retains the stage, never retries. Readiness schema is `do-usb-owned-claim-diagnostic-readiness-decision-v1` and fixes device58. The default CLI is dry; execution requires a reviewed manifest and fresh parent readiness digest/output directory.

The native15-second budget is cooperative checks around fixed metadata/claim operations. Remote45/host75 foreground bounds remain in the wrapper; a blocked syscall can outlast the cooperative check and must not be reported as a completed lifecycle. Native tests cover ten ABI/precondition/shape checks; wrapper tests use fake root responses and malformed receipts. Cleanup's native exceptional paths are reviewed statically, not claimed to have injected syscall-failure coverage.

Official upstream Linuxv5.4.261 sources are retained with hashes/licenses in upstream-linux. usb.c registers usbfs_driver; driver.c binds it, devio.c tracks file-private claim/release and reads GETDRIVER from kernel interface state. UAPI usbdevice_fs.h defines uint32 interface plus256-byte driver name, total260; ioctl_IOW('U',8,260)=0x41045508. These are same-version upstream sources, not attestation of Samsung's running kernel. They do not prove actual .NET symlink results, which this probe records.
