# GR: global operating selector4 and RTP category1 are different namespaces

**The retained global selector is4, while the selected source conditionally uses RTP dispatch/category argument1. They are not contradictory values of one field.** “Mode1” without the namespace is ambiguous and must not be published as a claim that global R+`0x10` equals1. This additive correction preserves all frozen GJ/FA/GD/GL/GN artifacts and earlier reviews.

For current summaries, use: **“sampled global operating selector4; AA0/AC2 selects RTP category1 in the selected source, conditional on reaching the corresponding dispatcher. The sampled category1 aggregate did not exceed40 in the GJ raised trial.”** Category selection is not a PC trace, continuous register observation or actual-FP proof. The compact checkpoint rows do not retain R+`0x10`.

## Retained bytes and actual guards

All28 full R windows inspected here contain the halfword4 at R+`0x10`:10 control/retained R windows in GJ's raised recorder receipt,10 in its40-control receipt, three each in the actual FA set/restore receipts, and GP's two baseline EB R windows. Each receipt is pinned in `validation.normal.json`; FA/GP embedded raw hashes are rechecked, and GJ recorder window lengths and whole receipt hashes are bound. The retained M windows checked alongside them have AA0/AC2. This does not establish global4 at every compact row, between samples or in other runs.

FA's native `Profile` has bytes`04 00` at offset`0x10`; this offset is neither historical/dynamic nor a modeled field. Its `GuardR` requires those exact bytes. The actual set baseline passes the frozen offline guard; changing only this halfword to1,3,5 or6 refuses with `remaining exact profile byte16`. Thus **FA required global4 through its static profile**, not global1. Its README “Mode1 aa0/ac2/scan1” and native error text “mode1 flags” describe the AA/AC category condition imprecisely; they must not be interpreted as a global1 guard.

FN's `Context` checks the root, AA0/AC2 and finite scan/geometry/context fields. It contains no explicit global R+`10`==1 requirement. Its sampled global4 is an observation; a receipt/transport qualification must not be described as proving a global1 guard. GR does not relax or change any native, parser, readiness or writer condition.

The historical GJ phrase “sampled mode1 aggregate” can accurately refer to the selected category1 H slice, but the public current narrative must make that scope explicit. It cannot establish global1, actual comparator category at every invocation, actual FP, a physical outcome or a causal threshold benefit. GJ's Hmax36 at200 remains below40; GR adds no above40 witness or prevention result.
