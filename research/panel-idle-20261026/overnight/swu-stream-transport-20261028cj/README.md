# Fixed-range TLS section transport

Host-only qualification, no TV/root/TEE operation. .NET 6 client source implements the frozen CG IChunkSource/IChunkSink interfaces; Python 3 server uses only the standard library. The library does not import target native libraries or alter TEEC frames.

C# API: `new SwuStreamTransport.TlsSectionChannel(new ChannelOptions(ServerIpv4, Port, CertificateSha256, Nonce, CipherBytes, CipherSha256, MaximumOutputBytes, IoTimeoutSeconds:10, TotalTimeoutSeconds:90))`. Certificate pin is SHA256 of exact DER certificate bytes, lowercase64hex; nonce is exactly32 private random bytes. Constructor connects/authenticates once. Caller supplies a strict local config parser and fixed SectionPlan; Begin validates cipher count/hash. Pass one channel as engine source and sink. Dispose closes only. No reconnect or implicit completion. Abort sends F only if framing remains healthy; uncertain connections close and retain host partial output.

Python API: `serve(ServerConfig(source_path, source_offset, cipher_bytes, cipher_sha256, maximum_output_bytes, certificate_path, private_key_path, nonce, output_directory, bind_ipv4='198.51.100.10', port=0, io_timeout_seconds=10, total_timeout_seconds=90), ready_callback)`. All paths are fixed absolute local paths, never wire input. Source may be the verified whole firmware file with a fixed offset/range. Server prehashes that exact range before listening, then calls ready_callback with only host/actual port. Parent may thread this callable and seal target config using the selected port. One accept only; no retry. Start after target staging when a ten-second accept budget is used.

Fresh output leaf under an owned private parent is required. The leaf is created0700, output private.partial0600; clean C renames to raw-complete.bin in the same private leaf. This is raw quarantine only. It does not establish padding, expected original length, plaintext CRC/signature, full schema, firmware applicability, target cleanup, or client receipt of the final ACK. Input is independently rehashed while streamed and checked at EOF. A concurrent file mutation or failed/ambiguous transport retains partial or completed quarantine; never automatically retry or promote. Output may contain zero bytes: expected output length is a later parent validation gate.

Wire grammar, all integers big-endian: H + CGT1 +32nonce -> A,H,u32(0); R+u32(request1..65536) -> D+i32(actual0..request)+data; W+u32(length1..65536)+data -> A,W,u32(length); C -> A,C,u32(0); F -> A,F,u32(0). Errors use E+u16fixedcode then close. C requires exact input count and EOF; engine calls it only after normal native cleanup, but server cannot independently attest that cleanup. R/W counts and aggregate output are bounded. Fragment progress loops operate only on transport/files; no TEEC retries occur. Both ends use TCP_NODELAY.

TLS1.2+; client accepts only exact pinned DER certificate, then sends nonce. No CA fallback. Nonce/config/certificate pin/digests/content are never logged by production source. Application-private arrays are cleared where held; TLS/runtime/kernel copies are not wipe-qualified. Socket I/O defaults10sec; total budget1..7200seconds interrupts blocked network handles. The pure engine and ordinary regular-file kernel calls cannot be forcibly cancelled by this library; parent must retain its native/host outer deadlines. ACK loss after host rename remains ambiguous to client.

Build `Transport.csproj` and `ClientTests.csproj` using pinned local net6SDK with cleared NuGet sources, then `python3 test_transport.py` and `python3 -O test_transport.py`. The reference to CG DLL is read-only; no frozen CG project is rebuilt. Synthetic tests use only localhost and an ephemeral self-signed certificate, never firmware data. There is no live entrypoint, server CLI, target integration, or secret example config in this package.
