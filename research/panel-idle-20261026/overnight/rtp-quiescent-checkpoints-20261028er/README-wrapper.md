# ER read-only Clean/Quiescent checkpoints

ER is a host-built derivative of frozen EM with unchanged fixed reads R,M,C,P,N,H,L,R, native binding, request/reply phase handling and one-Left worker. It performs no vendor data writes, extra address reads, reset, policy setting, code hook or retry. Parent is the sole target coordinator. This implementation performed no target, root-adapter, network or OEM execution.

The native recognizes exact stop0/fault0/gate0 **with R+c4==40** as `Quiescent`, packed nibble3. This name means a source-compatible gate-disabled observation, not CPU inactivity, safety, physical picture or fault prevention. Clean0 and Faulted1 retain their prior exact triplets; all other unexpected states retain fail-closed behavior. The source bridge is frozen EQ: image0 gate-off215bc can clear only ordinary gate and related AP_EXCO flags without setting stop/fault.

The first full eight-read cycle must bracket Clean/Clean before the key starts. Initial Quiescent, including a first-cycle Clean→Quiescent end, refuses without a key. After that baseline, Clean and Quiescent starts/ends continue the same fixed reads. A completed nonfault cycle is counted Clean only if both R reads are Clean; any completed nonfault cycle containing Quiescent increments `quiescentCyclesCompleted`. A fault transition increments neither completed nonfault counter. `onsetObserved` continues to mean a Faulted triplet, never Quiescent. Unexpected/malformed/transport/binding errors still stop.

One rolling raw capture slot retains the latest complete nonfault cycle, with truthful role `last-clean` or `last-quiescent`; no extra capture buffer is added. The trigger baseline remains a separate retained duplicate, not a counted new cycle. `cleanCyclesDiscarded` counts completed clean cycles absent from this rolling slot; retaining a duplicate baseline does not subtract another cycle. A clean-to-quiescent change can therefore leave all prior clean cycles discarded from the rolling slot while their compact records and baseline remain. Partial transitions preserve original raw data and never invent a complete checkpoint.

The preallocated compact buffer is **56 ×58 bytes**. Its first54 bytes are the EM layout, including distinct R classification nibbles. Offset54 adds end-R+0xca u16, offset56 adds end-R+0x68 u16, little-endian. These are already-read source bytes. The first is a source selector mirror, the second a known trainer-arm control; neither is proof of an instantaneous executing branch. Source fields remain sequential, with only the H full request/reply bracket compactly timed. A captured zero cannot rule out an intervening writer, and the current C7 cannot be inferred from an earlier cycle's M/C/H.

Requested cycle-start period is25ms, cooperative observation ceiling2s, maximum56 cycles. The zero-overrun fake path ends at1.4s, first-to-last H span1.375s. USB service time is subtracted before sleeping; an overrun produces no pacing sleep. Actual rate, number of cycles and exact transition coverage are not guaranteed. Binding still precedes the observation clock. Each bulk keeps its2s timeout, root45s/host75s deadlines and pending-IN completion obligation after a fully accepted OUT. There is no native process alarm. Up/worker cleanup may finish after the final USB sample.

The receipt cap remains24576 bytes, opaque stdout16384, stderr2048, root response65536 and generated command8192. Exclusive semantic files are0600 inside a fresh owned0700 `/tmp/researcher-er-<32hex>` stage. Diagnostic stdout cannot become semantic JSON. Ambiguous/failing native runs retain the stage and evidence; success cleanup is exact. New semantic schemas and readiness are ER-specific. An initial refusal is not a successful wrapper observation and needs separate source-bound classification/cleanup.

The strict decoder validates Quiescent directly in raw R capture bytes and packed nibbles. It recomputes separate native clean/quiescent counters from the compact trace and every retained compact byte against raw sources. It never substitutes Clean for Quiescent to satisfy a parent parser. Its lower transport validator was explicitly extended for the state, counters and rolling role. Key/baseline checks remain full-Clean first-cycle, one down/up workflow and actual completed-R coverage at/after Down begins. Host `workflowQualified`/`trialQualified` cover that workflow; `rtObservationOutcome` distinguishes CleanOnly, QuiescentObserved and Faulted. None establishes UI receipt, emitted light or causation. No-quiescent rows do not prove that gate disable never occurred between samples.

`prepare-readiness.py --wrapper er` is a cached-only derivative of EM's builder, requiring a pinned wrapper, current identity, explicit phase note and evidence. It performs one ordinary cached identity/FD census request if centrally executed and creates no endpoint-queue proof. Only mocked execution was used here. `run-once.py` remains dry by default; the frozen deployment manifest, source inventory and independent review must identify the candidate before parent target use.
