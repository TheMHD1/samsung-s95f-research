# Fixed-200 read-only checkpoint recorder (EY)

This is a host-qualified derivative of frozen ER. It is not a writer or an automatic experiment coordinator. Production requires a separately prepared, digest-bound readiness decision and an explicit one-shot execute request. No target execution was performed during this implementation.

Every R classification first requires little-endian u16 at R+0xc4 to equal 200. At that fixed limit, Clean is (stop,fault,gate)=(0,0,1), Faulted=(1,0x1001,0), and Quiescent=(0,0,0). A wrong limit is Unexpected even if its other fields look Clean or Faulted. The initial full cycle must be Clean/Clean before the single normal Left down/up workflow; an initial Quiescent or Faulted observation is retained as a refusal, not promoted to an onset. A later Quiescent observation remains distinct from Clean and does not prove CPU inactivity, protection bypass, a fault, or a physical state.

The eight-read cycle remains R 0x47012400/256, M 0x470004a0/68, C 0x47000bc0/16, P 0x47000490/16, N 0x4700ba28/36, H 0x4700d0e0/96, L 0x47010f00/64, R again. Each read is a fixed target-0x101 header plus its matching IN. The transport, native device binding, key worker, ReadPair, ReadSet, lifecycle, cleanup and 58-byte compact layout are inherited unchanged. There are no arbitrary address/value arguments, controller writes, reset, retry, catch-up sampling, or automatic restoration. The only existing production argument is the canonical expected USB device number bound to readiness. At most 56 cycles run with a cooperative two-second observation deadline and a requested 25-ms start-to-start period. Matching IN obligations survive a deadline/clock error after a complete OUT; ambiguous/short transfers stop further headers. Blocking native IO is not preempted by the cooperative timer. Key join and root/host budgets remain inherited.

Both raw RT decoders and all compact start/end limits enforce 200. The additional offline verify-observation.py admits only an accepted, qualified, closed one-shot capture with the exact manifest, raw inventory, all retained R limits 200 and complete cleanup. Time/CycleLimit may end Clean or Quiescent; TransitionCaptured requires latest retained Faulted. No Quiescent-to-Clean projection occurs.

Counterfactual Above40 metrics deliberately remain at 40. A compact contextual witness requires Clean/Clean, sampled H low16 >40, C7=1, and the end-R selector mirror at +0xca equal to 1. Full retained contexts separately report AA/AC, scan, root, C7, R selector mirrors and limits; only a full retained same-cycle mode1/alternate context supports a same-cycle witness. Compact rows do not contain AA/AC, so a retained baseline or later context cannot establish every intervening row's mode. The publication-bound mirror is not actual FP selection, H/R/M/C reads are sequential, and neither actual comparator calls nor emitted light are proven. Missing a >40 witness leaves a clean-at-200 test inconclusive.

The separate frozen DV writer remains responsible for restrictive mode1, thermal, echo, callback, identity and exact-profile admission, and fixed set/restore transactions. A faulted/scan-disabled context cannot use its restore action. A separately qualified recovery and fresh identity/readback must determine the actual current limit and admission context; MODE2 is not assumed to restore 40, clear all RAM, or reload code. Changing c4 also changes a publication capacity bound, so an observed difference is not a pure comparator intervention or established root-cause fix.

Host validation uses the existing local .NET 6 SDK, empty NuGet.Config, and owned host-environment directories. Run build-host.sh for fake-only suites. Cached-readiness tests replace the root adapter with a mock; wrapper tests use mock root records. Reviews are independent and excluded from the frozen source inventory. Existing ER/DV sources and actual captures remain unchanged.
