# Addendum: cross-core AP_EXCO selector bridge

This is an additive finding after the first DF report/graph freeze. All addresses are conditional selected-package source identities; the live complete image0 identity remains unproved. This bridge does not connect the unrelated image0 0x584109a4 table to the image1 packed RTP aperture.

The selected image1 resource-address translator VA0x1bb74 maps mode0 code addresses<0x40000 by adding0x44000000 and SRAM addresses0x20000000..<0x20020000 by adding0x25000000. Mode1 instead uses0x46000000 for code<0x20000 and adds0x27000000 to SRAM. These are source-derived cross-core aliases, not merely an assumed CPU/bus map. VA0x1bc24 is invoked with mode0, directory selector0x1000c and name AP_EXCO. Its directory walk uses byte-count/entry-size and name matching, then translates entry+4 through that mode's mapping.

Selected image0 (FILE=VA+0x200) directory VA0x1000c is [count_pointer0x3c3d0,stride12,table0x3c3b8]; byte count24. Entry VA0x3c3c4 is [name_pointer0x3dd8c,context0x200158a8,length0x3ec]. The name at0x3dd8c is AP_EXCO. Thus image1's CPU0x2cc pointer is populated with the remote AP_EXCO context alias0x450158a8, and its +0x3d8 read is remote address0x45015c80, corresponding to image0 CPU0x20015c80. Do not confuse this with image1 SRAM alias0x4701....

The separate image0 directory at0x10000 has stride28 and includes AP_EXCO entry0x3cbd4: [name0x3dd8c,data0x2000ff14,bytes0x33a,default0x2001024e,bytes0x1200,extra0x1b0000,extra0x1b0400]. Image0 getter0xe678 returns data0x2000ff14; getter0xe76c returns context0x200158a8. Writer0x2fb44 gets those two objects, calls0x2f5d8 and conditionally0x2f980, then at0x2fb60..2fb76 writes context+0x3d8 as `((data.u8(+0xe6)&1) | data.u16(+0x2fc)) !=0`. The following change handler0x2fb7c compares context+0x3d8 with+0x3d9, logs `slg-%s` with `on` or `off`, calls0x33580 on the enabled transition, then records the latest state. The short source label SLG is established; an expansion or physical meaning is not.

This closes an actual inter-core control path: AP_EXCO data/config-derived boolean on image0 → image0 context+0x3d8 → image1 resource alias → C+7 → alternate threshold/fixed-A branch conditions. Upstream writers/calculation of data+0x2fc, the semantic meaning of data+0xe6 bit0, and the physical aperture producer remain open. There was no live read or write of these addresses. The prescribed P/N capture remains unchanged; no additional cross-core MMIO is added automatically.
