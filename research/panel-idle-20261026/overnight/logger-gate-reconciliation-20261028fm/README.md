# Logger gate reconciliation: fixed restore-only helper

FM is an additive one-shot helper for restoring the original stock logger halfword to0 after the rejected FH/FG observation. It has not been deployed or run on the TV. FH's original native and wrapper refusal are preserved; an independent phase proof establishes completed pairs and a terminal `ReadyForHeader` with release/close, not successful observation or permanent queue emptiness. FM does not clean, overwrite or reuse FG's retained stage.

There is no arming, UI action, key worker, threshold write, reset, instruction patch, ring read, address parameter or automatic retry. The only permitted write is target0x102, address0x47012406, length2, fixed payload`0000`. A full gate halfword1 permits that one write;0 is a distinct already-zero/no-write result. Upper-bit drift refuses. Successful readback is required; completion of the payload is not treated as verified restoration.

## Fixed lifecycle

The native path uses the qualified DQ/FG ARM32/root, fixed boot/bus7/interface2/descriptor/expected-devnum validation. It opens one FD, claims once, validates the locally owned binding through exact GETDRIVER`usbfs` plus native statx followed/canonical device+inode equality, and releases/closes in `finally`. These ownership and FD functions are byte-identical to FG. Only the backend header/payload whitelist narrows to R/M/C and payload0000.

It allocates all five response/transfer captures before preflight. Fixed fresh reads are **M→C→R**, with R closest to the write. Geometry requires2160/1920/2880, Ccategory92, C7<=1; M root20010000, AA0/AC2 and source-bounded scan0/1. Scan is asynchronous and is not required to synchronously match R. R must be one of Clean0/0/1, Quiescent0/0/0 or Faulted1/4097/0, at actual threshold40, configured reference limits200/200, aggregate gate1, and the existing four alternative latches/gates zero. All remaining checks are retained.

Only C8's **restore-only** allowlist is0 or3. FL proves image1 VA3956/3958 copies derived MULTI/AP_EXCO+0 into this byte; source image0 VA3277e/32780 clears that byte through stock runtime callers. C7 comes from a different source field. The source getter/root and the logger sink are separately qualified, so C8zero alone does not mean a replaced root. FL's full source audit and inventory are pinned. Values1/2/4 also exist in source; this helper refuses them. It makes no global0/3 domain claim and does not widen FG arming or observation readiness.

For gate1, the helper submits one fixed12-byte write header and its matching2-byte0000 payload, followed by a fresh R requiring full logger halfword0 and the same fixed R profile. This is five headers/ten bulk calls/four INs/one payload. Gate0 skips the write and still obtains a second R: four headers/eight bulk calls/four INs/zero payloads. Snapshots are sequential, not atomic. Concurrent changes after the fresh checks are not excluded.

## Phase and clock rules

FG's `ReadPair` is copied byte-for-byte. Every accepted read header receives exactly one matching IN even if a later timestamp fails. The restore header likewise receives its one fixed matching payload despite after-header clock failure. A failed/short/throwing transfer leaves phaseUnknown and no later header is sent. A pre-header clock failure or insufficient budget sends no header. No matching transaction is retried. Release/close still run; unknown transfer ownership is not repaired by cleanup.

The whole cooperative budget is30s, with2s per bulk and4s per pair. Each new read reserves its own4s and the remaining fixed pairs. The write requires8s remaining for itself and readback. The worst five pairs consume20s of their nominal bulk timeout bounds, leaving10s for cached preflight, claim/release and other overhead. These are cooperative admission checks, not a hard syscall/scheduler/process-death guarantee. Accepted work requires end<=deadline. A completed write followed by failed/missing readback is refused and reports that the logger may remain; there is no second write.

## Local and remote provenance

`run-once.py` is dry by default. Its explicit execution path requires exact manifest and readiness hashes before importing the root adapter. FM readiness includes the existing fresh cached identity/unbound/census and explicit parent closed-world lineage premise, plus `restoreOnlyPremise` with exact fields: accepted, phaseReadyForHeader, released/closed true, priorNativeAccepted false, loggerOriginallyZero/loggerMayRemainOne true, and the fixed FH phase proof path/hash. The loader rehashes that proof and every bound original input and corroborates prearm0→armed1 and terminal Ready/released/closed in the original receipt. It does not reinterpret FH's refusal as acceptance or infer continuous absence of clients.

The bounded wrapper derives FG's ordinary stage/census/exclusive-file/three-blob framing and exact integrity cleanup. It removes wake/UI work and both ring sidecars. One fresh `/tmp/researcher-fm-<32hex>` stage owns exactly nine files: three pinned payloads, selftest receipt/stdout/stderr, and native receipt/stdout/stderr. Exact original FG files are not in this allowlist. A zero-I/O selftest precedes fresh immediate metadata and exactly one production invocation. Native stdout is diagnostic only; the exclusive private semantic receipt avoids GC interleaving. A refused/ambiguous native receipt is retained and causes no further wrapper requests. Only accepted Ready/released/closed/device-bound results proceed to post-census, exact nine-file integrity and removal.

Root45s, host75s, command8192, response65536 and receipt24576 caps remain unchanged. Native stdout/stderr caps remain16384/2048. There is no autonomous recovery or retry after any ambiguous stage, invocation, transfer, file or cleanup operation. The fixed device argument binds accepted readiness devnum, not arbitrary USB paths or caller addresses.

## Host qualification

Run `sh build-host.sh`; build scratch stays under this directory's HOME-backed `host-environment`. The empty NuGet source list prevents dependency downloads. Native fake cases cover Clean/Quiescent/Faulted, finite scan and C8, gate0/1, alternative/profile/root/geometry drift, every transfer's short/error path, all timestamp positions, pre-header refusal and post-header mandatory IN/payload completion, deadline refusal, release/close and receipt bounds. Normal/-O Python checks independently bind inherited source and FL/FH proof inputs, reject malformed receipt/counter/hash/context variants, generate syntax/bound-check mocked stage commands, test both no-write/write paths and verify exact nine-file cleanup with no UI or rings. No real adapter or TV is invoked by these tests.

The native receipt is capped and retains all raw M/C/R bytes, transfer records, return counts and timestamps. `parse-result.py` admits only a complete exact successful lifecycle, reconstructs pair counts, verifies every raw extent/SHA256 and typed field, recomputes context/R checks, and distinguishes already-zero from verified write/readback. Native errors remain rejected and retained. This helper restores a stock logging gate; it does not establish optical state, actual FP, event caller, whole-image identity, root cause or universal recovery.
